# JeekSubCut

以瀑布流字幕为起点、面向完整视频剪辑能力演进的**模块化**视频编辑工作台（Windows 桌面端）。

> 同类效果在剪映里叫「翻转大字 / 快闪旋转」，抖音·快手·视频号上常被称为「快闪字幕」「旋转大字」，B 站网友则习惯叫它「倒鸭子」—— 就是那种文字随节奏旋转、逐条弹出涌动的卡点文字视频。

> 名字里 `Sub` 是 Subtitle 的行业通用缩写，`Cut` 是剪辑。指向的是「用字幕驱动剪辑」这件事，而不是把功能锁死在瀑布流这一种排版上。

- 作者：Jeek（B 站「[吉客AI / Jeek AI](https://space.bilibili.com/3706973113551694)」）
- B 站主页：<https://space.bilibili.com/3706973113551694>

## 一、这是什么

你可能也在剪映里用过它：选「翻转大字」模板里的「快闪旋转」样式，文字就随节奏旋转着逐条弹出、向上涌动 —— 本软件做的就是这一类效果。行业里它常被称为「瀑布流字幕」「快闪字幕」「旋转大字」，B 站上大量教程标题则直接写「倒鸭子」，抖音 / 快手 / 视频号上那种卡点文字视频多半是这一种。

字幕不是一条条淡入淡出，而是像瀑布一样从画面锚点持续涌出、向上流动、旧行被新行顶走。所有字幕都是矢量文字，导出时按比例整体缩放，不会因为改分辨率而糊掉。

打开软件就是一个完整工作台：上方工具栏、中间实时预览、底部双轨时间轴、右侧字幕列表与属性面板。字幕卡片可以直接拖动、裁剪、切分、改字；音频可以导入、录音、按波形对轨；识别结果能自动转成字幕；最后导出视频、SRT 或工程文件。

## 二、架构：为长期扩展而设计

目标形态是一套完整的视频剪辑软件 —— 多轨道编辑、素材片段、视频特效、转场、人像美颜、画面调色，以及之后新增的任何能力。架构只围绕一条主线：**把能力切成互不认识的模块，让它们只通过内核定义的契约对话**。

```
apps/          组装层：desktop / editor / render-service
features/      功能模块：timeline / subtitles / preview / audio / asr / export / …
engine/        合成与渲染抽象（RenderProvider 可替换实现）
core/          内核：工程文档 / 命令撤销 / 事件总线 / 模块注册表 / 持久化
contracts/     契约层：只有类型与接口，零实现零依赖
```

依赖严格单向、只朝下。每个功能是一个独立包，只向注册表「贡献能力」（轨道类型、面板、命令、工具、检查器、设置、效果、导出格式）；界面里的工具栏、右侧面板、设置项与导出格式都由这些贡献点生成。完整设计见 [docs/PLATFORM.md](docs/PLATFORM.md)。

| 层 | 选型 |
| --- | --- |
| 仓库组织 | npm workspaces monorepo（Node 自带，无需额外工具） |
| 语言 | TypeScript strict（类型即契约） |
| 编辑器 | React + Vite，状态按模块 slice |
| 渲染 | `RenderProvider` 接口 + 按帧求值引擎，实现可替换 |
| 桌面壳 | Electron（无边框自绘窗口、原生对话框） |
| 边界约束 | 自研零依赖检查脚本，随仓库走 |
| 测试 | Node 内置 `node:test` + 浏览器行为探针 |

## 三、快速开始

### 1. 安装

在**仓库根目录**双击 `安装依赖.bat`，等它自己跑完即可——脚本会自动下载内置 Node.js 并用它装齐全部依赖，系统无需预装任何运行环境。

仓库里只有源码，运行时、二进制和模型都不在仓库中。安装脚本会把它们补齐，最终目录结构与开发用的 `app/` 完全一致：

| 步骤 | 做了什么 | 产物 |
| --- | --- | --- |
| 引导 Node.js | 自动下载内置 Node.js（带 sha256 校验），系统无需预装 | `install/runtime/node/` |
| `npm ci` | 按 `package-lock.json` 装 npm 依赖，版本与开发机一致 | `node_modules/` |
| `npm run build` | 编译 contracts / core / engine / features，构建编辑器 | 各包 `dist/`、`apps/editor/dist/` |
| `npm test` | 架构边界检查 + 契约 / 行为 / 端到端闭环 | 162 项全绿 |
| 下载运行时 | 按 `install/deps.json` 从国内镜像取 Electron、ffmpeg、语音识别引擎与模型 | `resources/` |

下载前会实测各镜像速度、优先走最快的源，传输中若持续过慢会自动切换镜像并从断点续传；全部组件带 sha256 校验，已装好的会自动跳过，重跑脚本很安全。安装结果记录在 `resources/install-state.json`。可选组件（ffmpeg、识别引擎与模型）下载失败不影响程序启动，联网恢复后重跑一次即可补齐。

### 2. 启动

双击 `启动.bat`。它会依次拉起：

```
渲染服务   http://127.0.0.1:5174   /api/v1/health
编辑器     http://127.0.0.1:5173
桌面窗口   Electron（未安装 Electron 时自动改用系统浏览器）
```

关闭桌面窗口或按 `Ctrl+C`，三个服务会一起收干净。想改源码即时看效果，用 `启动.bat --dev` 走 Vite 热更新；只想看界面，用 `启动.bat --browser` 强制浏览器打开。

### 3. 等价命令行

所有批处理都有等价命令，便于在终端、CI 或非 Windows 系统里使用：

```bash
npm run setup          # 同 安装依赖.bat
npm start              # 同 启动.bat
npm run start:dev      # 编辑器热更新
npm run start:browser  # 强制浏览器
npm run check:launch   # 只检查安装状态，不启动
npm run check:deps     # 只探测下载地址是否可达

npm test               # 架构边界 + 契约 / 行为 / 端到端回归
npm run test:types     # 编辑器 TypeScript 严格检查
npm run smoke          # 真起一遍服务：健康接口 / 页面 / 渲染 / 识别 / 转码 / 404
npm run smoke:desktop  # 再加：真起 Electron 窗口，验证界面行为并截图
npm run dev            # 单独启动 Vite（http://127.0.0.1:5173）
npm run serve          # 单独启动渲染服务（http://127.0.0.1:5174）
```

`npm test` 会先跑 `tools/check-boundaries.mjs`：强制依赖方向单向、功能包之间零互引、跨包只用公共出口、依赖必须声明。它跑在没有安装任何 lint 工具的机器上，规则随仓库走。`npm run smoke` 是启动链路的行为探针：临时占用 `5193`/`5194` 端口，真起服务、发一次真实渲染请求、调用本地识别与转码端点，然后自动收干净；加上 `--desktop`（即 `smoke:desktop`）还会真起 Electron 窗口，用调试端口驱动真实界面：检查工具栏按钮、时间轴卡片、预览画布像素、改字后同步、主题切换、设置与模块面板，并生成一张界面截图到 `output/.probe/editor-ui.png`。

安装脚本的常用参数（写在 `安装依赖.bat` 后面即可）：

| 参数 | 用途 |
| --- | --- |
| `--check` | 只探测各镜像地址是否可达，不安装 |
| `--only electron` | 只装某个组件 |
| `--force` | 强制重新下载组件 |
| `--no-test` | 跳过测试，加快安装 |
| `--asset-source DIR` | 从一份已有安装的 `resources/` 离线复制，全程不联网 |
| `--cache DIR` | 指定下载缓存目录（默认 `install/.cache`） |

| 音频面板 | 音频文件与波形概览、音量、录音状态、关闭音频（关闭后录音不会拼接旧音频） |
| 录音 | 选录音设备、调录音音量（0~200%）、系统降噪 / 回声消除 / 自动增益 / 高通滤波四个开关，实时看波形与电平；录完自动接到音轨末尾，并显示「已录制 mm:ss.s · 已插入音轨」 |
| 字体目录 | 提供 5 款简体中文 Windows 系统字体（微软雅黑 / 黑体 / 宋体 / 楷体 / 仿宋），直接调用系统已装字形，不随程序打包；可导入本地字体（`.ttf` / `.otf` / `.woff` / `.woff2`，单个文件最大 200 MB，完整中文字体也能用），选完字体文件预览立即按真实字形显示，拷进 `fonts/` 目录的字体打开字体管理时会自动收录，逐条设为默认或删除；左栏「全局字体」与字幕列表的「自定义字体」都用它 |
| 设置 | 视频比例、帧率、导出分辨率；三者都与预览画布和成片尺寸联动 |
| 窗口 | 无系统菜单栏；右上角自绘最小化 / 最大化·还原 / 关闭按钮，与界面同风格；双击顶栏空白处在最大化与还原间切换；切换深色主题时整窗（含顶栏按钮）自动变深 |
| 导出 | 选 MP4（不透明）/ MOV（透明，带完整 Alpha 通道，可直接导入剪辑软件）；面板实时显示「预计体积」与「临时空间」（临时帧落盘位置与所需大小、该盘可用空间，空间不足会红色预警并在导出前拦截）；文件名、保存位置（桌面端可「选择」目录）；编码器 MP4 用 H.264 / H.265、MOV 用 ProRes 4444 / 4444 XQ；分辨率（1080P / 1440P / 2160P）、帧率；编码速度（快速 / 标准 / 精细）+ 画质 CRF 滑杆（MP4）或画质档位（精细 / 标准 / 轻量，MOV）+ 编码加速（自动 / 显卡 / CPU，MP4）+ 并行帧数；导出中显示真实帧进度与编码方式，完成后在导出目录里直接打开 |
| 语音转字幕 | 三阶段流程：提取时间轴音轨 → 本地识别引擎 → 分句对齐落轨，带时间戳时按时间戳对齐 |

主题：界面右上角可一键切换浅色 / 深色主题；程序会记住你上次的选择，下次启动自动沿用，不用每次重设。深色模式下自绘窗口栏也会同步变深。

导出说明：导出格式只有 MP4 与 MOV 两种。MP4 不透明、体积更小，适合直接发布；MOV 带完整透明通道，适合叠到其他画面上再合成。透明背景的工程默认选 MOV，不透明默认选 MP4。MP4 的编码加速选「自动」时先用显卡 NVENC，显卡不可用就自动退回 CPU，成片照常出来；只有明确选「显卡」而本机 ffmpeg 没编进对应硬件编码器时才会停下来提示换档。MOV 由 CPU 按帧并行做 ProRes 4444 编码，画质由「画质档位」控制，透明通道始终完整保留。导出前面板会预估「预计体积」和「临时空间」（逐帧渲染先把画面写成临时图片、编码完自动删除，空间必须落在保存位置所在盘），该盘空间不足会直接红色预警并拦截，不会等到导出到一半才报错。字幕可以导出 SRT / VTT / TXT / JSON 四种格式，导出时弹出保存窗口，位置和文件名都由你选（默认名 `subtitles.srt` 等简短英文名，可自行修改）；工程文件可以存成 `.jeek` 再载回来（默认名 `project.jeek`），旧版本存下的工程也能直接打开。

常用快捷键：

| 键 | 作用 |
| --- | --- |
| `Space` | 播放 / 暂停（播到末尾停在末帧，不回绕） |
| `Ctrl+B` / `Delete` | 在播放头切分 / 删除选中卡片 |
| `Ctrl+T` | 在播放头插入字幕 |
| `Ctrl+H` | 打开查找替换（可填查找词、替换词、区分大小写，一键替换全部） |
| `Q` / `W` | 以播放头裁剪卡片左端 / 右端 |
| `I` / `O` | 打导出范围的起点 / 终点 |
| `←` / `→` | 逐帧步进；`Shift` 5 秒、`Alt` 1 秒、`Ctrl` 5 帧 |
| `↑` / `↓` | 跳到前 / 后一张字幕或音频卡片的开头 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `Esc` | 取消选中（弹出面板请按面板上的关闭按钮，轨道三点小面板也可以点面板外关闭）；在底部文本框里按 Esc 会同时结束编辑 |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 撤销 / 重做（整包快照，350ms 内同类操作合并） |
| `Alt`（拖动时） | 临时关闭吸附 |

底部文本框：选中卡片时直接改这条字幕的文字，没选中时输入的是待插入草稿。按 `Enter` 结束编辑并保留选中，按 `Esc` 结束编辑并取消选中，`Shift+Enter` 换行，`Ctrl+Enter` 直接把文本插到播放头位置。

滑块吸附：所有滑块都有轻微吸附 —— 每隔 10 档有一个吸附点（例如 0 / 10 / 20…，音量增益的 -30 / -20 / -10 / 0 / +10 / +20 / +30 dB），只在靠近一个刻度时才吸，仍可停在两档之间细调。**按住 `Alt` 拖动可临时关闭吸附**；时间轴上拖动卡片时按住 `Alt` 同样是临时不吸附。

## 六、本地开发：四目录工作流

开发机上的项目根分成四个各司其职的目录：

| 目录 | 用途 | 是否提交 |
| --- | --- | --- |
| `legacy/` | 上一代实现的完整快照，作为行为回归对照 | 否 |
| `app/` | 实际测试工作区：日常改源码、装依赖、跑构建与测试都在这里 | 否（只取纯净源码） |
| `GitHub/` | 纯净源码镜像，唯一用于提交与推送的目录 | 是 |
| `bin/` | 打包输出：可上传 Releases 的便携版压缩包或 setup 安装程序 | 否 |

工作流：

```
在 app/ 修改并实际测试
  → npm test / npm run build 全绿
  → node sync-to-github.mjs        # 项目根执行，把纯净源码镜像进 GitHub/
  → 进入 GitHub/ 提交并推送
  → 需要发布时，在 bin/ 产出成品并上传到 Releases
```

`sync-to-github.mjs` 会把 `app/` 的内容映射到 `GitHub/` 的根（不带 `app` 前缀），按白名单带上安装脚本、启动脚本与 `install/deps.json`，同时过滤掉 `dist/`、`node_modules/`、`resources/`、下载缓存与本地开发资料。同步结束会做一次交付自检：缺少入口文件或混入构建产物都会直接报错。`bin/` 只放成品，不参与日常开发。

## 七、如何扩展一个功能

1. 在 `packages/features/` 新建包，只依赖 `@jeek/contracts` 与 `@jeek/core`；
2. 导出一个 `JeekModule`，在 `activate()` 里注册贡献点；
3. 在 `apps/editor/src/modules.config.ts` 的清单里加一行。

不需要改动其它功能包、内核或引擎。新增视频轨、特效、转场、调色、美颜时，差别只是贡献点类型与 `RenderProvider` 的一个新实现。

## 八、当前能力

- **内核**：可序列化的工程文档（轨道 / 片段 / 效果节点）、帧级时间量化、整包快照式撤销重做、模块注册表与贡献点、事件总线、工程文件读写与版本迁移。
- **编辑**：时间轴基础操作、时间码与视频长度、缩放与适配、拆句并句、自动填充与消除缝隙、卡片不重叠约束、多选与框选。
- **画面**：11 种入场动效、历史层堆叠、整组旋转（顺 / 逆 / 交替 / 随机 / 按间隔）、0.25 秒过渡、屏幕适配、纯色 / 图片 / 透明背景、横竖屏与方形画布；文字描边（单层外 / 双层 / 内描边、颜色与 0~16 px 粗细，默认白色 5 px）与字幕轨整体不透明度，预览与导出走同一份渲染；入场动画默认 350ms；全局动画改一次即统一所有字幕，字幕列表里仍可单条覆盖；字幕位置提供屏幕适配比例（屏幕适配风格）与水平 / 垂直位置滑块（其他风格），水平位置同时控制左对齐字幕的左边距与右对齐字幕的右边距，两边对称。
- **音频**：导入本地音频、波形绘制、按 `{startMs, endMs, inMs}` 重建音轨、分块录音并追加到音轨末尾、关闭音频后不拼接旧音频；录音带实时波形监控与电平表，录下的时长就是音轨上的时长，不会把时间轴撑长；整轨基础降噪（高通 + 噪声门）、逐片段响度统一、分贝增益（`-∞` 静音、`-30 ~ +30 dB`）在预览、导出与语音转字幕三处共用同一份处理结果。
- **字体**：提供 5 款简体中文 Windows 系统字体（微软雅黑 / 黑体 / 宋体 / 楷体 / 仿宋），直接调用系统已装字形，软件不内置也不分发字体文件；需要其它字体可自行安装到系统或「导入本地字体」（单个最大 200 MB，`fonts/` 目录里拷入的字体打开字体管理时自动收录），全局与逐条字幕都能单独指定。
- **识别**：本地 SenseVoice + FSMN-VAD，三阶段窗口，识别对象是时间轴实际音轨，结果按帧率量化落轨。
- **导出**：离线逐帧渲染画面 + 本地 ffmpeg 编码，仅 MP4（H.264 / H.265，NVENC 硬件加速、自动回退 CPU）/ MOV（ProRes 4444 透明，CPU 按帧并行）两种容器；分辨率 1080P / 1440P / 2160P、帧率、编码速度、CRF、加速档、并行帧数换算成确定参数；导出前预估成品与临时空间并预检磁盘，空间不足直接拦截；支持按 I / O 范围出片；字幕导出 SRT / VTT / TXT / JSON；工程存成 `.jeek` 并兼容旧版工程文件。
- **分发**：仓库只存源码，安装脚本补齐运行时与模型（不分发任何字体，避免授权问题）；启动器一键拉起三个进程，边界检查与行为探针随仓库走。

## 九、环境要求

- Node.js 无需预装：安装脚本自动下载内置版本（当前 v22.22.2，带 sha256 校验），系统里有没有 Node 都能装
- Windows 10/11 x64（桌面壳目标平台；编辑器本身可在任意现代浏览器打开）
- 本地端口 `5173`（编辑器）与 `5174`（渲染服务），仅监听 `127.0.0.1`
